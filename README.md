# Syntecxhub Simple Calculator

## Project Description

This project is a simple command-line calculator developed as part of the Syntecxhub internship.

The calculator performs basic arithmetic operations such as:

- Addition
- Subtraction
- Multiplication
- Division

## Features

- Simple command-line interface
- Supports repeated calculations
- Input validation
- Handles division by zero
- Separate functions for each arithmetic operation
- Exit option
- Basic testing of calculator functions

## Technologies Used

- Python
- VS Code
- Git
- GitHub

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python calculator.py
